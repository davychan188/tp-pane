開啟 GeoPackage
電腦：點擊或拖放 .gpkg。電話：用上方「開啟 GPKG」。

iPhone 可能灰掉 .gpkg。可先在電腦按 Save .sqlite for iPhone，再傳去 iPhone 開啟。

地圖 Map
可從 openstreetmap.org 匯出小範圍 .osm 再匯入。然後再開樹木 GPKG。
密集 GPKG 開啟後會自動關閉編號；開啟後僅於縮放／視窗內顯示，以減少 iPad 卡頓。
無需 GPKG · Import
可只匯入清單，或只匯入地圖 PDF；兩者互不阻擋，不必開 .gpkg。
媒體 Media

媒體可獨立匯入，唔使對應地圖／清單。可選檔名前綴（如 T1_defect.jpg）方便「只顯示呢棵樹」。

尚未載入 PDF — 請按「媒體資料夾」選 PDF（可雙指縮放）（右側為 PDF 頁面；清單／地圖互不依賴）

點選樹木以檢視屬性與媒體。需要移動時再開「移動此點」。
